I build at the intersection of applied AI, quantitative systems, scientific computing, and product engineering. Based in Bengaluru.

## Projects

**[zeroH](https://github.com/cosmic-hydra/zeroH)** &mdash; A Python layer for grounded memory, retrieval, claim verification, and abstention. Wraps any LLM with a deterministic verify-reask-abstain loop using SQLite-backed memory, sentence-aware chunking, and confidence scoring. No heavyweight ML dependencies.

**[ZANE](https://github.com/cosmic-hydra/zane)** &mdash; AI-native pharmaceutical OS unifying target intelligence, molecule generation, free-energy physics, preclinical safety triage, and lab execution. Funded by AMD and NVIDIA.

**[vecomp](https://github.com/cosmic-hydra/vecomp)** &mdash; A Rust vector index with Python bindings that shrinks high-dimensional embeddings to ~2GB via quantization-aware retrieval.

**[Tetra Quant](https://github.com/cosmic-hydra/tetra-quant)** &mdash; Quantitative trading research infrastructure on OpenBB. Data ingestion, backtesting, and signal analysis.

**[Concepts](https://github.com/cosmic-hydra/Concepts)** &mdash; AI-native note-taking app applying grounded retrieval to personal knowledge management.

**[Hydra Fund](https://github.com/cosmic-hydra/hydracorp)** &mdash; Software and research infrastructure for an AI-native investment platform.

## Principles

**Determinism over heuristics.** Stochasticity is a tool, not a default.

**Composable over monolithic.** Small, standard-library-first primitives that compose well.

**Evaluate honestly.** Grounding verification, abstention rates, and failure mode analysis over inflated metrics.

**Ship real things.** Applied research that produces software people can use.
