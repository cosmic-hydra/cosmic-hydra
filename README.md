## About

I build at the intersection of applied AI, quantitative systems, scientific computing, and product engineering. Based in Bengaluru.

The projects here share a consistent thesis: that the most impactful systems in AI, science, and finance benefit from determinism where it matters, rigorous evaluation, clean interfaces, and composable primitives over monolithic frameworks.

<br>

## Projects

<br>

### <a href="https://github.com/cosmic-hydra/zeroH">zeroH</a>

<br>

> Zero Hallucination for AI agents

A standard-library-first Python layer for grounded memory, retrieval, claim verification, citations, and abstention. Bring your own LLM (any API or local provider), and zeroH wraps it with a deterministic verify-reask-abstain loop that pushes hallucination rates toward zero using durable SQLite-backed memory, sentence-aware chunking, confidence scoring, and citation emission.

<br>

### <a href="https://github.com/cosmic-hydra/zane">ZANE</a>

<br>

> Pharma OS for Autonomous Molecular Engineering

AI-native pharmaceutical operating system unifying target intelligence, molecule generation, free-energy physics, preclinical safety triage, compliance telemetry, and lab execution interfaces into a single orchestration-grade runtime. Funded by AMD and NVIDIA. Every molecular decision is generated, stress-tested, and cryptographically auditable through governed decision gates.

<br>

### <a href="https://github.com/cosmic-hydra/vecomp">vecomp</a>

<br>

> Vector compression via TurboQuant

A vector index written in Rust with Python bindings that shrinks high-dimensional embedding footprints to roughly 2GB for practical-scale corpora. Exploration into quantization-aware retrieval for resource-constrained deployment.

<br>

### <a href="https://github.com/cosmic-hydra/tetra-quant">Tetra Quant</a>

<br>

> Quantitative trading research infrastructure

Pipeline-driven data ingestion, strategy backtesting, and signal analysis built on the OpenBB platform for systematic research.

<br>

### <a href="https://github.com/cosmic-hydra/Concepts">Concepts</a>

<br>

> AI-native note-taking with PNAS-backed retrieval

Personal knowledge management that applies grounding and verification primitives from agentic systems to daily notes and ideas.

<br>

### Hydra Fund

<br>

Software and research infrastructure for an AI-native investment and venture platform. Portfolio analytics, market data pipelines, and the research stack underpinning systematic decision-making.

## Operating principles

|  |
| --- |
| **Determinism over heuristics** -- especially in evaluation, retrieval, and agent behavior. Stochasticity is a tool, not a default. |
| **Composable over monolithic** -- small, standard-library-first primitives that compose well, inspired by the Unix philosophy applied to AI systems. |
| **Evaluate honestly** -- benchmarks that measure what matters: citation-grounding verification, abstention rates, and failure mode analysis over inflated accuracy metrics. |
| **Ship real things** -- applied research that produces software people can use, not papers that produce more papers. |
